# 팀원(국가별 리포터) 공통 업무 지침

입력: 국가 코드 `<cc>`, 날짜 `<DATE>` (YYYY-MM-DD, KST)
출력: `data/<DATE>/teams/<cc>.md`

## 절차

1. **RSS 수집**
   ```bash
   python3 scripts/collect_headlines.py --country <cc> --date <DATE>
   ```
   → `data/<DATE>/raw/<cc>.json` 을 읽는다.

2. **실패 매체 보충** — `ok: false` 이거나 헤드라인이 0건인 매체는
   - `homepage` 를 WebFetch 해서 메인 헤드라인 5~10개를 뽑거나,
   - WebSearch (`<매체명> headlines <DATE>` 등)로 보충한다.
   - 그래도 못 구하면 "수집 실패"로 남긴다. **헤드라인을 지어내지 않는다.**

3. **정리** — 매체별로 최근 24~36시간 핵심 헤드라인을 최대 10개.
   광고·연예·스포츠·생활정보는 제외하되, 경제·정치 함의가 큰 경우는 남긴다.

4. **ID 부여** — 국가 전체에서 일련번호 `[<CC>-n]` (예: `[US-1]`, `[KR-12]`). 팀장·임원이 이 ID로 출처를 추적한다.

## 출력 형식 (`data/<DATE>/teams/<cc>.md`)

```markdown
# <국가>팀 헤드라인 — <DATE>
수집: <collected_at> · 성공 매체 n/m · 수집 실패: <매체 목록 또는 없음>

## 방송사
### <매체명>
- [CC-1] 원문 제목 — 한국어 번역 (발행시각) <링크>
...

## 신문사
### <매체명>
- [CC-9] ...

## 교차보도 이슈 (2개 이상 매체가 다룬 사건)
| 이슈 | 보도 매체 | 관련 ID |

## 자국 시각 메모
- 이 나라 언론이 오늘 가장 크게 다룬 것, 프레이밍(누구 편에서 쓰는가), 자국 이익과의 연결 3~5줄.
- 국영/당 기관지 매체는 "국영" 표시. 정부 입장 전달 창구라는 점 자체를 기록.
```

## 원칙
- **임시 파일은 반드시 `data/<DATE>/tmp/<cc>/` 에만** 만든다. 스크래치패드 등 공용 폴더는 9개 팀이 동시에 쓰므로 서로 덮어쓴다.
- 저장 직후 출력 파일의 ID가 모두 `[<CC>-n]` 접두어인지 확인한다.
- 번역은 짧고 정확하게. 원제는 그대로 둔다.
- 분석·평가는 "자국 시각 메모"에만, 짧게. 중요도 판단은 팀장 몫이다.
