# 2026-10-26 브리핑 (1차 시스템 보관본)

main 구조로 통합하기 전, 별도 브랜치에서 5단계(팀원 → 팀장 → 임원 초안 → 팀장 검토 → 임원 최종)로 만든 브리핑이다.
82개 매체(방송사+신문사) 수집 기준. 기록용으로만 보관하며 현재 파이프라인에서 쓰지 않는다.

- `briefing.md` — 최종 브리핑 (분야별 피쉬본 SVG 포함)
- `work/teams/*.md` — 국가별 팀원 정리본 (출처 ID `[US-n]` 등의 원본)
- `work/lead_digest.md`, `work/exec_draft.md`, `work/lead_review.md` — 팀장 선별 · 임원 초안 · 팀장 검토
- `work/fishbone/*.json` — 피쉬본 원본 데이터
